# 🕒 Pomodoro Timer

## 🍅 What is it?

A simple **Pomodoro Timer desktop app** built using **Python and Tkinter**.  
It helps you stay productive by breaking your work into intervals — traditionally 25 minutes of focused work followed by short breaks.

This timer automatically cycles through:

- ✅ **Work sessions** (25 minutes)
- 💤 **Short breaks** (5 minutes)
- 😴 **Long break** (20 minutes after 4 work sessions)

---

## 💡 Features

- 🕹️ Start and reset buttons
- 🔁 Automatic switching between work/break cycles
- 🧠 Tracks up to 4 sessions before a long break
- 🖼️ Custom UI with a tomato image (Pomodoro 🍅 themed)
- ⏱️ Countdown in MM:SS format

---

## 📦 Requirements

- Python 3.x
- `tkinter` (included in standard Python installs)
- `tomato.png` image in the same directory as the script

---

## 🚀 How to Run

1. Clone the repository or download the script.
2. Make sure `tomato.png` is placed in the same directory.
3. Run the script with:

```bash
python pomodoro_timer.py
